# Agent Kickoff Template

Use this when handing a workstream to a separate implementation agent.

## Required Reading

- `docs/implementation-plan.md`
- `docs/coordination.md`
- `docs/workstreams/<assigned-brief>.md`
- `THIRD_PARTY_ASSETS.md`

## Required Output

- implementation plan for owned files
- research-backed technical decisions
- explicit dependencies on other streams
- proposed acceptance criteria
- list of risks and fallback scope cuts

## Rules

- do not edit outside your owned file set without explicit coordination
- treat the shared contracts as the source of truth
- do not expose hidden seat metadata to clients
- cite research sources when they drive architecture decisions
