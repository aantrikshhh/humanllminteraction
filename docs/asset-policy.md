# Asset Policy

## Primary Style

- Use Kenney as the primary house style.
- Keep one tile size and one UI family per gameplay surface.

## Approved Supplemental Sources

- `0x72 DungeonTileset II`
- `0x72 DungeonUI`
- `ansimuz top-down collection`
- selective `OpenGameArt`

## Attribution Rules

- Credit the supplemental sources above whenever used.
- Credit OpenGameArt per asset, not per site.
- Track every asset in the theme manifest before merging.

## Required Manifest Fields

- `assetId`
- `source`
- `pack`
- `assetPath`
- `author`
- `assetUrl`
- `license`
- `licenseUrl`
- `requiredAttribution`
- `creditText`
- `usedIn`
