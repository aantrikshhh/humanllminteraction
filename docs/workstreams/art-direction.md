# Art Direction Workstream

## Owns

- `packages/theme`
- asset ingestion rules
- palette, typography, spacing, motion rules
- future asset manifest and credits generation

## Must Not Own

- game logic
- ranking logic
- provider logic

## Responsibilities

- establish a consistent house style across website and games
- define approved use of Kenney, 0x72, ansimuz, OpenGameArt, and Game-icons
- normalize tile size, palette, line weight, and UI density
- define scene families for each game

## Research Focus

- pixel UI composition
- Tiled to Phaser pipeline
- attribution automation

## Interfaces Published

- theme tokens
- component styling rules
- sprite and icon registry
- asset governance manifest format

## Acceptance Criteria

- every screen has a consistent visual language
- third-party asset usage is traceable and credited
- supplemental packs are used intentionally rather than mixed blindly
