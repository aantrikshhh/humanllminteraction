# Website Workstream

## Owns

- marketing routes under `apps/web`
- copy hierarchy, public content sections, credits page shell

## Must Not Own

- room protocol
- private player/profile state
- game rules

## Responsibilities

- design public site IA
- build landing page, concept pages, game catalog, company-facing explainer pages
- coordinate with art direction for visual language
- expose credits and third-party asset acknowledgements

## Research Focus

- responsive landing structure
- strong visual presentation for a game benchmark platform
- SEO and performance constraints for Next.js public pages

## Interfaces Needed

- theme tokens and approved art assets
- public game metadata
- public leaderboard teaser data

## Acceptance Criteria

- site clearly explains human-vs-hidden-LLM concept
- all public pages are mobile-safe and visually consistent
- credits surface is present for third-party assets
